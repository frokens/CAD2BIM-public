# Geometry 编写

## 职责与形体

Geometry 根据局部输入构造实体并报告模型接口。它不替 Family 搜索安装站位，不读取或修改外部管道。优先复用适用的现有 Geometry；固定形体与参数化函数依实际用途选择，参数化函数不得以缩放固定设备掩盖安装不适配。

先明确局部原点、轴向、单位、端部朝向和真实尺寸。优先简单可解释的工业构造：圆柱、圆弧、局部直锥等；仅在业务形体需要时使用复杂放样或更多布尔。不要用增加源码量衡量精细度，也不要为了显示顺滑制造无依据的复杂过渡。

分体拼接关注近重合边界、相切和扣孔顺序，避免没有业务用途的碎面、零厚度或堵塞。不能只因面狭窄就宣布缺陷；以实体、边界或显示诊断的实际失败为依据。不把 clean、某个容差或盲目加重叠当万能修法。

外观/安装模型先保留主要轮廓、尺寸、贴合净空和实际使用的端部；只有用途要求时才增加隐藏流道、螺纹、小孔和圆角。用户允许近似时，在usage说明哪些内部结构未表达；任务已要求的贯通、密封、净空或制造特征不能自行省略。批量建模先考虑一次拉伸/回转和有依据的布尔顺序，见[批量成本与布尔顺序](construction-methods.md#批量成本与布尔顺序)。不要把某个构造顺序或一次样例提速推广成所有Geometry的硬规则。

## 参数与接口

### 局部形体与摆放

Geometry选定稳定的局部原点与轴，在该坐标中构造形体并定义接口；整体安装位置、整体旋转由Family的component/fragment放置变换承担。相同规格零件仅换安装位置时，不应生成一套带新世界坐标的建模参数，或在build末尾整体translate/rotate。固定资产同样通过放置变换安装。

区别整体摆放和真实形状：整件弯头转向不改变局部主体，弯头自身弯曲角、管道长度/折线路径、端部斜切及支管相对夹角仍是几何输入。不要为了参数相同而删除这些量或对真实尺寸任意取整。几何内部为形成台阶、支管、偏心结构而使用相对平移旋转是正常建模，不是禁止所有translate/rotate。

接口也在同一局部坐标内定义，使用放置变换还原到产品/项目坐标。端点用逆平移加逆旋转换到局部，轴和参考方向只做逆旋转；不要在变换后重新按世界Z方向生成参考轴，造成实际周向关系改变。对非圆截面或明确检查roll的端口，保留所需的相对参考方向；形体外观一样不代表全部接口语义一样。

修订现有资源时，同步Family绑定参数、Geometry evaluate/build及样例说明；用同一实例的原世界结果和新局部结果加放置变换比较主体、端点、轴与必要参考方向，再选一个整体旋转/平移代表。无需作者实现缓存、分组或理解后台Worker，也不增加注册资格、缓存字段或性能门槛。

参数合同只公开真正变化、会影响调用的输入，写清类型、必要单位、默认与边界。固定结构常数留在实现中，不把每个中间量都暴露成调用参数。源码实际消费、Schema 和 Family 绑定必须一致；数组结构、长度及边界按当前受限方言表达，不自行引入通用 JSON Schema 能力。

参数边界来自已声明需求、可用输入和准确依赖，不能由少数示例或任意经验数值反推。逐个参数合法不保证组合合法，须明确耦合条件及依赖假设；偏好尺寸与必需可行条件分开。说明中区分声明支持域、已实际验证的案例和未知范围，类型及数值边界仍以 Schema 为准。

modeling_function 在独立 `interfaces.py:evaluate(ctx)` 中按正规化参数声明局部位置、向外轴、参考方向和profile，正常返回None；`main.py:build(ctx)`只返回Shape。evaluate和可达helper不导入main/CadQuery/OCP、不读取Shape或geometry_inputs；可在纯数值helper中共享尺寸推导。不能为取得接口先build或扫描端面，也不能在Write的mapped_model interfaces分支替代函数接口。固定mapped创作可在build声明接口，正式使用以准确manifest为准。作者用有限代表保存体检查参数推导的接口是否与约定端部一致；名义接口或合法近似必须明确，不能当成实际开孔或贯通证据。

编写前按需要读取当前 Geometry Write program_api 与参数合同资料，使用公开能力和既定入口，不直接绕过 Runtime 调用后台私有实现。

## 保存与使用说明

Write 保存源码、参数合同、必要依赖及使用说明，成功只表明草稿已保存，尚未完成实际构建。依赖使用准确可读资源，遵守当前 Geometry 依赖类别；不要把 Family 可用的绑定形式推定到 Geometry 输入。

usage_instructions 仅补充合同不能表达的调用条件、锚点意义、形状与接口随参数变化的规则、假设及限制。外观简化尤其说明隐藏内部是否表达、是否允许据模型检查流道或制造；不重复Schema、算法逐行解释、单轮性能数字或通用工具流程。

保存后选择必要代表构建与观察；如何选例、复用和结束见 Preview 指南。任务单独提供实现时也必须替换当前引用、核对公开合同，并以本次实际执行判断结果。
