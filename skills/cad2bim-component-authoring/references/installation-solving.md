# 安装求解：先约束，后构造

本页提供可选择的工程思考方法，不是后台自动能力，也不是特定产品的完整算法。准确尺寸、允许表示、参数域和接口语义由本次需求及资源合同决定。

## 把图形问题转成少量变量

先按 [Family 输入决策](family-authoring.md#接口和约束) 区分独立输出目标与计算资料，再分清不可改的事实、产品硬约束、用于选择可行解的设计偏好，以及允许求解的站位、姿态和连接件参数。固定设备尺寸不参与拉伸；可行区间由硬约束决定，偏好只用于选解，不暗中成为尺寸上限或下限。只搜索部分允许域而未找到解时，应说明实际搜索范围，不能据此报整个允许域 INFEASIBLE。也不要把所有尺寸都变成优化变量。finite_segment 的起终点 S、E 定义本次调用的允许范围：u=(E−S)/|E−S|，接入点 S+t·u，0≤t≤|E−S|。这是允许接入的窗口，不是产品应当耗用的长度，也不表示已存在真实外管；起终点已表达该范围，不再增加第二套许可子区间参数。首次安装或维护时，在原域内派生调用子窗口、统筹相邻管段及处理设计例外，由 `cad2bim-installation-maintenance` 负责。该输入的轴不能任意延长；确需无限轴时使用 infinite_axis，固定接入点使用 fixed_point。资料的来源不会自动决定它属于独立断言；计算输入须有明确的类型、单位和用途。

在产品局部坐标中解决尺寸和装配，再统一映射到世界坐标。点受旋转和平移影响，方向只旋转；不要混用局部、产品和世界坐标。入口轴、出口轴与端面外法线分开定义。通过一个整体刚性变换代表案例检查世界原点依赖，比给每个坐标穷举更有效。

优先用解析区间与必要条件排除明显不适配，再对真正剩余自由度做有界搜索。先选满足硬约束的候选，再比较紧凑、简单或其他明确目标；不能用评分弥补接口、许可区间或固定设备尺寸违约。

适用的可变连接构件应在真实形体、端口、壁厚／通道、必要过渡及明确工程限制满足后，合理减少占用，为后续构件保留可用空间。比较实际两侧接入占用及相关实体包络；不是仅移动声明端口或缩小报告的包围盒。尺寸下限需有来源或明确设计依据，不伪造制造标准；也不统一取最小半径、最短过渡。用少量相关候选和实际约束解释取舍即可，不为此建立通用优化平台或声称全局最优。

## 从弯头抽象：有限空间内的转向与占用

先区分同轴直通、共面转向、平行偏移和异面输入；它们不是把同一公式改个角度就能统一处理的分支。当前资源不支持的情况应明确，不能移动源管来伪装支持。

对两条相交中心线的圆弧转向，若 θ 定义为沿流向的偏转角、R 为中心线半径，理想切线退距为 R·tan(θ/2)。这只描述圆弧，不包含直颈、法兰、异径过渡、壁厚或构件外包络。把这些真实占用分别加入两侧站位限制后，才判断是否装得下。θ 的定义不能直接套用两个端面向外法线的夹角。

半径不是越大越平顺就越好，也不是只能固定为某个管径倍数：先遵循资源／产品的设计限制，再核有限窗口内的占用。不要为了接口坐标吻合给弯头附加没有业务理由的长直尾。

接近退化情形时，按原始连接条件已有的位置、方向及截面容差评价候选，不只按某个数值是否严格为零决定可行性。角度小不保证空间误差小，应结合实际长度和占用估计误差，再用生成形体的真实端面核原条件；不能改写来源方向、放宽容差或伪造端口来凑解。满足现有业务容差的简洁表示可以作为候选，超出容差时仍需处理实际差异；不要把某次有效的数值阈值推广为所有尺寸的默认值。

异径可以先把转向主体与局部口径过渡分开设计，便于分别约束半径、长度和壁厚。局部直锥适合简洁工业外形；复杂圆顺放样只有形体需求确实需要时才采用。方案选择不改变原接口输入。

## 从调压器／阀组抽象：固定核心与两侧适配

先确定主体和其真实端口，再把两侧连接视为“给定外管端口到主体端口”的适配问题。不能先把整个设备拉到两端，再补说明称尺寸固定。

两侧虽然可以复用同类连接 Geometry，但共享主体的一个位置和姿态，不能完全独立求解后硬拼。先联合选择主体布局与两侧有限站位，再分别求连接段；核两侧长度非负、许可区间、端口方向和外部空间，不只检查中心距。

压力侧、流向和设备端口身份来自业务输入，不能按图上的左右、外径大小猜测。若资源明确允许主体缩放，形体和接口一起按其规则变化；固定设备则不缩放。旧资源曾允许的缩放区间不是所有调压器的规范。

法兰、连接件、仪表应共享清楚的基准与唯一尺寸来源。重复几何可以复用一个绑定，但每个实例有自己的位姿和接口来源；不要为每个放置位置重新创建等价 Geometry。

## 搜索失败如何解释

有可行候选说明找到一个满足已检条件的解，不代表最优；有限搜索没有找到，不证明连续域内全部无解。区分支持域拒绝、硬条件冲突、搜索／信息不足和执行异常。

简化层级仅在当前业务及资源明确允许时使用，并说明保留与损失的语义。不能把精细构建失败或明确装不下改成名义球体并宣布详细安装成功；本次必验的无解仍应独立返回具体原因且不构建假结果。必要时返回具体未满足的条件，供调用方调整输入；不要静默扩大接入范围。

选定候选后按[Preview 闭环](design-preview-loop.md)验证同一次实现。接口、孔道及显示异常应回到各自责任层，不能都通过修改求解参数掩盖。
