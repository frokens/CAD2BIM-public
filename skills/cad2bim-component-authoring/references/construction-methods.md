# 几何构造：选简单表达，针对风险检查

本页是方法选择指南。可调用的函数、对象类型、单位和限制以当前 Geometry program_api 为准；不把 CAD 库的所有功能都假定为已开放。

## 按形体选表达

| 形体特点 | 优先考虑 | 需要留意 |
|---|---|---|
| 同轴台阶、颈部、凸缘和锥段 | 少量基本体或一个清楚的旋转截面 | 截面闭合、内外轮廓和最小壁厚 |
| 圆弧管路／弯曲主体 | 明确中心线与截面的扫掠或旋转构造 | 弯曲半径、截面朝向、退距与端面 |
| 局部异径 | 有明确长度的直锥或必要过渡 | 保持端部尺寸，避免内孔延长误切壁厚 |
| 多支相通空腔 | 分清外材料与应连通的空腔，再安排布尔顺序 | 后续融合不能把已开孔重新封住 |
| 重复安装同一零件 | 复用几何绑定，变更实例位姿 | 不能重复缩放尺寸或共享错误接口身份 |
| 特殊自由曲面 | 在需求确实需要时用放样等构造 | 截面方向、拓扑复杂度和可解释性 |

不是越圆滑、越多细节就越符合工业形体。先保证主要轮廓、比例、局部过渡和接口；装饰细节只在目标尺度下确实可见或有业务作用时增加。不要把图片上的光照、遮挡或渲染线当作实体结构。

先把整体摆放与局部形体分开：相同规格不要因为整件安装坐标或朝向不同就调用不同的几何输入。Family给出放置变换，Geometry保留真实相对形状和接口取向，方法见[局部形体与摆放](geometry-authoring.md#局部形体与摆放)。不要在作者代码里另写跨调用缓存或后台分组逻辑。

## 先明确端部，再组织主体

给出端面中心、向外方向、外轮廓和必要孔径，再约束主体如何连接这些端部。函数接口先由独立evaluate按同一参数推导，build依这些尺寸构造；用有限代表的保存体核对二者一致。参数或形体语义改变后更新受影响的推导，不能保留旧端口声明去“证明”新形体吻合，也不为求接口先构建实体。

若合同允许近似形体保留来源连接基准作为名义接口，应声明并检查名义基准与实际端面的允许差异。名义 frame 配对通过不证明真实端面重合；求解器使用的占用包络仍须保守包含实际简化形体。

同轴截面应能说明外材料与内孔边界。多分支空腔需要考虑全连接路径，端部有孔不等于中间贯通。一个清楚的候选是先组织外实体和连通空腔再扣孔，但它不是所有模型必须采用的唯一布尔顺序；按实际操作数与结果选择。

能减少不必要布尔的构造通常更易理解，但操作次数不是唯一指标。不要为了省一次操作把简单锥段和直颈变成难控的整体自由曲面。

## 批量成本与布尔顺序

优先去掉会重复处理同一交界面的构造，再考虑小循环优化：

- 同轴台阶可用一个闭合截面一次回转，直体能按最终长度拉伸时不先做过长实体再切两端；仅在结果和端面要求相同的适用条件下替换。
- 若最终必须统一切去同一空域H，先对A挖H、再与B融合、最后再挖H，可能让内核反复处理重合内边界。可比较`((A-H)∪B)-H`与`(A∪B)-H`：集合相等时仍须核当前内核的有效性、贴合和必要开口，不能只凭布尔次数推断更快。操作数拓扑通常比表达式长短更影响成本。
- 反方向也要检查：分别把各支体做空心再融合，可能重新封住交汇流道，并不普遍等于从融合外体统一扣孔。实际要求贯通时不能拿有孔端面代替中间通道检查。
- 外观级交付经允许可以省略非必要内部细节，将可见凹腔纳入同一截面；盲腔不等于贯通孔。若流道/制造是要求，保留其几何与对应检查，不能为速度偷偷换成盲腔。
- 同一build内复用未变Shape的截面、向量、拓扑枚举结果；Shape改变后重新取得相关面/边。不要在循环中反复求同一面中心/包围盒，也不跨invocation缓存不允许保留的Shape句柄。重复固定部件优先复用准确mapped资源与位姿；不同参数不得通过任意取整伪装为同一形状。
- 路径分段前区分真实转折与坐标运算产生的舍入噪声。无实际形体意义的分段可能同时增加原生构造和后续表示节点。若合同允许消除数值零转折，应按坐标尺度设置有绝对上界的误差，并核整条省略子链到最终保留线段的偏差；保留原端点和接口，防止逐点容差累积。不能用统一角度阈值把小但真实的弯曲改直。
- 对已证明共面接合且不发生其他穿插的实体，可在当前 API 支持时比较专用粘合选项与一般 fuse。先证明该选项的接合前提，再比保存体和时间；不能将简单弯头上的收益直接推广到可能自交的任意折线路径，也不能在失败后悄悄换算法。

计划大量实例化时，先用少量常见真实参数和必要非正交代表比较同一要求下的候选。看实际可获得的分阶段诊断，区分每组冷启动、纯build、Codec、IFC编码、保存与渲染；不能把一次冷启动乘以实例数，或把单个快例外推为全域保证。优先定位fuse/cut/intersect、sweep/loft/fillet及反复拓扑遍历，不凭代码行数猜瓶颈。没有计时能力时明确缺口，不在受控作者源码里导入计时器、profiler或私有Runtime来绕过工具。

估算批量收益时，按真实输入中受益条件的数量和分布加权；将共享启动、逐实例开支与累计目标模型的处理成本分开。几例构造加速的百分比不能直接乘整族总时间。候选改写未更快，或增加尚未解决的形体风险时，保留原实现并记录适用边界，不将尝试过的办法一律写成最佳实践。

这属于构造选择和有界Preview迭代，不新增注册性能资格、统一毫秒上限、全域试算或哈希凭证。已有必要检查和表示精度不因提速删除；技术错误也不能触发静默换形或换转换器。

## 稳健性问题先看接合处

仅相切、极小交叠、近重合边界、周期接缝和高长宽比的碎面都可能增加构造风险。用有业务意义的接合和尺寸关系处理，不盲目修改全局精度、无限加重叠或调用清理后直接宣布通过。窄面也可能是合法薄壁，不能仅靠面积或长宽比定罪。

设计允许时，可用清楚且有尺寸依据的实体交叠代替仅相切连接。调整周期接缝或表面分割若只修复一个输入，仍须核直接受影响的代表或反例，才能提炼为可复用规则；不因一次成功固化为默认构造。

保存回读后的曲面周期起点、接缝位置或边拆分可能不同，不能只凭面/边数量或参数数组不同判定形体改变。保留原失败，在同一准确保存结果上核支撑曲面、定向、实际裁剪边界及任务要求的材料关系；只证明所核范围内的数值或参数化等价。优化前后都被某个比较器拒绝不等于形体通过，也不能通过删除必要检查制造通过。

诊断时找到首个异常构造步骤和其操作数：结果是否缺失预期主体、包络突变、材料被切掉、端面改变？实体有效性、包围范围和关键截面应相互核对。单一 valid=True、空交集、闭合轮廓或网格状态为零，都不能独自排除实际形体问题。

对于已确认的边界自交、无效体或不合格构造，修 Geometry 并重验受影响代表；对于只确认显示异常的结果，先用保存体检查原几何和显示诊断，保留责任归因的未知部分。不能为修显示偷偷改变业务形体。

## 只检查本构造真正可能错的地方

- 异径过渡：观察局部轮廓和必要材料截面，防止过切、零厚度或异常圆鼓。
- 分体接合：看接合附近的实际端面、拓扑和孔道；不要重做整套产品的全部检查。
- 多分支空腔：检查能区分“开孔”与“贯通”的关键内部位置，而不是只重复测端口。
- 近退化近似：检查实际空间偏差和占用；声明近似就保留其限制。

探针和有限截面只证明所取位置的事实。只有任务要求相关内部质量时才增加对应检查；演示要求基本通孔时，不自动扩成精细流体／制造验证。

检查对象类型也要符合资源职责：曲面、壳或复合体可能就是合法交付，不能把“必须恰好一个闭合实体”作为所有 Geometry 的统一要求。多件装配与单件实体分别按实际产品合同检查。
