# Preview、观察和有限检查

## 选择必要代表

Geometry Preview 检查具体几何参数，Family Preview 检查产品求解、构建和接口。围绕实际主要构造／求解分支、分支切换、声明支持域边界及关键失败路径选择代表，不机械穷举每个参数和组合。任务已有固定输入时先保持输入，不依据失败结果改写题目。

按公开返回理解已完成的工作：SOLVED 表示已得到数值解；frame_check_status 和诊断给出内部声明关系及本行显式外部条件的 PASS／FAIL。正常 FAIL 仍可为 SOLVED，保留接口和残差而不提供几何或 inspection_ref；保存案例报告可复用这些数值事实。实际几何及 inspection_ref 说明可观察的保存构造，IFC 提交另按写工具结果判断。实体端面从实际保存 Body 观察，真实 IfcPort 及连接属于拓扑。各 Preview 案例独立处理，某例正常 FAIL 不阻止其它独立例；技术故障首错停止并保留此前完整结果。

正常案例应取得实际成功结果；预期拒绝应有对应业务原因，任意异常不算预期拒绝。求解允许偏离设计偏好时，用一个有可行依据、需要偏离默认偏好的代表检查取舍，避免把偏好当硬边界而漏解；已有代表覆盖这一风险就复用。必要代表、关键形体要求与相关失败路径已覆盖后结束；仅新增修改或真实缺口触发追加。

用于批量添加的Geometry也应关注代表构造成本，按[构造方法](construction-methods.md#批量成本与布尔顺序)定位最贵操作。复用同一组输入及保存结果，比较前后外观/安装要求、实际阶段时间和表示大小；冷启动、额外渲染与离线质量检查单列。只拿到工具总时间时，不将它冒称纯build时间。普通发布不因此增加强制基准套件或全域性能门禁。

任务要求合理紧凑时，对适用代表把“装得下”与“占用有依据”分开核：在相同外部条件和真实约束下，从同次保存体核接入站位、必要端部／过渡和相关包络，说明所留空间及尺寸取舍。不能仅以有限段内通过或 SOLVED 证明紧凑，也不把某个参考模型的尺寸当作所有产品的硬上限。复用已有形体与接口证据，只补占用相关的测量。

## 保存和观察

需要后续 Query、换视角或局部图时选择保存结果；一次性检查不需要留下固定模型时按工具合同使用临时模式。保存成功后保留每例 case_key 与 inspection_ref，不以草稿当前内容冒充旧案例来源。

已有体沿 Geometry Preview inspection 分支出图／截面，沿 Query 测量；不重新构建。一个 inspection 请求只对应一个保存体，可在其画布内使用多面板。不同安装体分别观察。局部 focus 使用实际可用的接口／overlay 标识，不猜内部编号；相机要匹配该模型的实际坐标和尺寸。

先选择能看清整体、关键接合和必要截面的少量视图。输出结构通常直接读本次返回，不把完整 result 资料作为每次调用前置。图片必须实际取得并展示，不能以文字声称已出图。

任务明确指定的轮廓或过渡特征，应在它所属的构形分支中实际存在；其他分支的相似形状、实体有效、接口匹配或部件数量不能替代它。复用同次保存图、截面和源码判断，不另加检查轮次；只核已约定特征，不要求参考实现的算法、尺寸或未约定的光顺标准。

参数变化会改变部件间关系时，区分全件共同变换与部件相对变化。对任务已要求的接合、净空等关系，用少量代表的同次保存结果核对相关变化；默认配置的证据不能自动覆盖其他配置，接口检查也不替代实体关系。只检查当前声明与用途有关的风险，不穷举全部参数组合。

任务约定留空或外部包覆时，检查最终合成体在实际接合区域的材料占据；远离该区域的正常截面不能证明局部留空。按该空间关系选取必要的局部截面、点分类或相交检查，复用同次保存体；不把所有重叠一律视为错误，不凭未知外部壁厚推定制造关系。

截面恰好落在边界或结论有歧义时，用邻近截面区分真实材料缺失与切面退化，不仅凭一张空截面下结论。报告对应的准确保存结果、对象、坐标、要求、实际测量及未检查范围。若缺少完成必需要求的能力或结果，应明确该要求尚未完成，不能只加一句局限说明便宣布全部验收。

## 外部安装环境的显示

同图显示外部管道和产品时，外管属于安装环境，不能为出图加入 Family。安装检查依据外部输入、选定接入点与产品真实接口；显示参考不参与连接检查，图片不代表已经裁管或写入真实连接。

当前 Preview 的 `reference_geometries` 可叠加已有 exact mapped-model 参考资产，需提供准确资源引用和显式放置；它们与产品主实体、求解及 Query 目标分离。保存结果会保留参考层，后续 inspection 可随该结果观察；inspection 输入不支持临时追加或更换参考层。准确参数读取当前 `common/preview#reference_geometries`，不猜字段。

需要快速看接合位置、方向和外径时，使用 connection_context.mode=auto：三种标准条件都从实际通过检查的产品端口沿向外轴画条件 OD 三倍长的短示意，不画到有限段端点，也不改变求解范围。缺条件 OD、实际端口或通过的检查时跳过并说明；不猜管径。普通 Geometry 无 Family 安装事实时不能用 auto。

需要展示指定连接区域时用 mode=pipes，每段只给 start_m、end_m、outer_diameter_m（结果坐标系，米）；不需要 CAD 来源、完整原管、内径或材料。后台不吸附或裁短，重叠也按输入显示，便于发现错位；手动示意不替代安装条件或自动端口检查。两种方式都只是独立显示参考，不表示真实管道、裁切或安装。准确字段从当前 Preview Resource 读取。

新执行省略/null 不生成背景；已保存 whole/result 观察省略/null 继承保存背景。none／pipes／auto 临时覆盖本次图片，原保存包与 Operation 不变，不重求解产品。示意仅在 whole/result 显示，组件/fragment、section 和 Query 不带背景；它不得进入产品 BREP、端口检查、产品统计或标准模型发布。任务缺少合适显示能力时仍报告缺口，不让作者用产品组件补洞。reference_geometries 仍不能直接接受参数化 Geometry 调用或任意 inspection_ref。数值成功不表示模型已构建或资源已发布，各自状态以对应工具结果为准。

## 复用与失败处理

输入、源码、绑定及相关行为未变且已覆盖同一风险时复用已保存结果，来源身份和 case_key 保持稳定，不因整理报告改标签而重跑。案例定义可以复用，不代表修改后的执行结果也可以复用；按实际影响重验。

区分参数预检、数值求解、Geometry 构建、保存、渲染与读取错误。依据首个失败阶段、字段路径和真实原因调整；仅解析出错不重发成功调用，同参数真实失败不无变化重复尝试。预算问题区分本次扫描／执行计数与返回量，按当前诊断处理，不把减小返回页数当作必然减少扫描。

已保存 Preview 的 `operation_get` 先给案例摘要和继续读取的导航。沿返回的案例游标遍历；需要请求、结果或报告级明细时，使用同一工具的 `preview_report` 分支及返回的内容定位，按字符续读并拼全 JSON 后解析。案例状态、读取是否完整和原 Preview 是否成功分别判断；大内容读取不需要重新求解或创建另一份报告。

构建成功但显示诊断失败时，图片不能用于确认外观；已有保存体仍可依公开 Query 能力定位。已确认不合格的几何需修订，不能删除问题区域或放宽目标；未证实的作者／后端责任不得武断归因。

接口检查与某项实体观察结论不同时，先核当前公开条件实际约束的对象、位置／方向／截面含义，再核它绑定的实际接口职责。区分条件或绑定选择错误、测量不足与后台实现偏差；证明某个几何关系正确，并不解除另一个已声明条件。依当前合同修正表达时保留原业务输入、来源和目标，说明表达改动及其理由并验证受影响案例；未解决的必需关系不能只写成“检查限制”后宣布完成。

按 [Family 输入决策](family-authoring.md#接口和约束) 区分计算资料与独立目标，再逐项核“条件约束什么、绑定接口代表什么、实际返回什么”。Family 的最低要求控制可接收的条件；none 或 profile_required=false 不会免除已提供的位置、范围或 OD 检查。失败诊断从原检查结果给出 interface、Geometry 绑定、失败维度与残差；按该对象定位职责不匹配或实现缺陷，不另造测量。没有外部目标时 external_target_comparison=NOT_COMPARED，内部 frame PASS 不能证明对外安装或实体接触；实体关系仍按任务要求从同次保存结果核对。修正表达须保留原业务事实与目标，再检查受影响结果。

## 完成范围

Write 保存、BUILT／SOLVED、接口检查、图片、Publish 分别表达不同事实。按当前任务要求核实体、接口、空间和外观，不自动升级到精细内部制造或流体。独立核收由指定角色负责时，作者不重复整套审计；真实未决项仍需报告。

报告列明实际读取的Package/资源、实际invocation、保存结果、已检查接口与外部条件，以及后续Query所观察的对象和坐标系；未调用的实体或连通检查明确为未检查。源包、中间推导包和最终包分别发现并按需读取，数据快照不等同本次真实Data查询。缺值和不可读取资料保留未知，不从最终包、SOLVED或已有图片倒推全链路已验证。

期待匹配只说明实际状态和理由与所填期待一致，不判断期待本身是否满足业务目标。完成结论依冻结任务、真实结果和已说明范围；不同合理实现可通过，不以与参考实现一致为标准。每项检查应对应实际使用中的错误，规则或测量本身有疑点时先查其依据，再归因程序；不因探索出另一种可能方案便事后增加必过要求。
