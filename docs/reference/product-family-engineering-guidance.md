# 产品族工程建模与诊断指导

本文供正式 Agent 在编写、选择和检查管网 ProductFamily 时按需读取。它提炼当前工程族的可复用方法，不提供某个 CAD 样本的尺寸答案。已实现的执行合同以 [Family 自身几何](product-family-self-geometry.md)、[模型接口](geometry-model-interfaces.md) 和当前 exact 资源为准；下文标为「建议」的步骤是后续工具、prompt 或 skill 的使用策略，不能当作已有自动能力。

Geometry 作者的通用构造、安装求解与有限检查方法由
[构件编写 Skill](../../skills/cad2bim-component-authoring/SKILL.md) 提供。
`cad2bim://contracts/ifc_geometry_resource_write/program_api` 保留准确编程 API、能力限制、
接口语义与合法请求示例；具体资源的 usage 给出该资源的适用条件和精度。
本页保留工程解释与按需追溯入口，不要求调用方同时全文加载本页和 Skill。

消费已有族并交付或维护IFC安装结果时，使用[模型安装维护Skill](../../skills/cad2bim-installation-maintenance/SKILL.md)。
下述资源作者的内部求解与Preview方法不构成每次产品安装的固定步骤；安装任务仍需按实际依赖维护跨产品关系，
单产品求解和保存成功不代替该业务检查。

资源作者把局部形体与整体安装位姿分开：Geometry保持稳定局部原点/轴并定义局部接口，
Family通过已有组件/片段变换放置；真实相对尺寸、路径、端面倾角和必要接口周向不能删除。
详见[局部形体与摆放](../../skills/cad2bim-component-authoring/references/geometry-authoring.md#局部形体与摆放)。
这是资源设计方法，不新增后台准入规则、作者缓存字段或Worker要求。

## 先确定输入、职责与证据等级

**当前输入边界。** public_parameters 承载 Family 声明类型、单位、来源及用途的计算与布局资料；invocation.external_constraints 对绑定实际输出接口施加独立目标断言。宿主事实不自动成为另一物体的接口要求。三种位置均显式给方向关系，OD 可选且受 Family 最低要求约束；已给 OD 始终比较输出接口圆截面。finite_segment 的两端点定义完整许可，fixed_point 表达固定点，infinite_axis 表达无限轴。准确分支及测量职责见[自身几何合同](product-family-self-geometry.md#产品原点与内外部约束)。

**已实现且复用的职责。** Family 程序只求数值参数、组件/片段、绑定选择和相对位姿。Backend 先预检整份 proposal，按选中 binding_key 取得 exact Geometry 的独立参数接口结果（函数执行 evaluate，固定模型读取已发布接口），完成内部及外部 frame/condition 检查，通过后才构建实体。Geometry 负责局部实体及随参数变化的模型接口；它不读取或修改外部管道。实体构造中的必要质量检查不替代前置接口检查。SOLVED、frame PASS、保存 BREP 和来源段关系检查各证明不同事实，不能互相替代。

**建议给 Agent 的工作顺序：**

1. 从当前 Package/Family/Geometry 的 exact 版本和资源说明取得输入来源、单位、合法模式、接口身份及限制；保留来源产品、管段和端口身份。不要从图片、某次成功参数或 Family 名称反推缺失字段。
2. 区分数值求解、实体构造、名义关系和安装四层。先检查标准连接条件、整段允许范围、数值 proposal 与独立参数接口结果，再看所选 Geometry 的保存实体及必要量测；不能让检查接口依赖先构建实体。关系检查读取完整关联成员，最后才讨论外管修改或 IFC 添加。
3. 每次判断写清触发条件、所读证据、使用的工具/资源、成功或失败分支、完成判断。复用已保存且输入、exact 资源和检查语义未受影响的结果；新增验证针对能区分处理方法的代表输入及原失败。

Family 的 `INFEASIBLE` 表示某项已定义约束或支持域未满足，不自动证明全部可选布局无解；`AMBIGUOUS` 表示当前数值或信息不足以证明结论。二者都要保留具体原因。受监督执行异常、预算停止、Geometry 布尔失败、Codec/保存失败或缺少完整 receipt 是技术失败或未执行，不可改写成业务拒绝、默认成功或部分通过。相同失败再试前先提出针对根因的变化。原许可域内的布局搜索、效果相当的构造选择和可逆数值修正按授权自主处理；只有需要越过既定业务约束、改变连接身份或验收目标，且存在重大非唯一取舍时，向用户说明选择与影响。

## 选择详细形体与合法简化

**已实现的例子。** TEE 在来源拓扑和三侧连接条件合法后求共同交点、有限窗口及主管/支管布置；详细候选的端口间距与包络不满足时，可选择其明示的 `default` 球形节点，保留三个独立名义接口、方向和 OD，并记录 `construction` 与 `default_reason`。来源角色/拓扑错误、数值容量不足或建模技术失败不能借此变为默认成功。REG 先尝试真实主体和两侧详细适配件，必要时在自身允许尺度内搜索；详细布局未找到再尝试真实主体加名义球形适配件的 `compact`，其后才是全节点 `node`。REG 节点还需要经来源/关联关系确认的连接站位；缺失或相矛盾的站位不会由调用者凭空补零。各级均返回完整组件、片段和两侧身份，Backend 只构建被选中的绑定。

**建议。** 让资源合同声明每种简化的准入、不可简化的输入错误、保留的接口事实和证据等级。Agent 应优先尝试该资源允许的正常解法，读取 `construction/default_reason`，并报告所得的是详细实体、带真实主体的名义连接，还是节点表示。不要把「详细布置未找到」写成连续设计域已被穷尽证明，也不要把 compact/node 的名义接口写成真实开口、接触、流通或制造可行。

这些已声明的名义表示保留其适用用途，不能替代本轮要求的详细有限空间安装成功或“明确装不下”的无解检查。必验无解须返回原因且不构建假结果；不因输入标准化扩展为删除全部 sphere/node 或引入精细内径、流体和制造验收。

## TEE：稳健布尔与有界微曲线表示

**已实现。** TEE Family 依据真实主管转角和尺寸/长度预算选择 `straight`、`curved` 或显式 `near_zero`。`near_zero` 仅用于极小非零转角且估计偏移在该资源预算内：物理主管沿角平分轴按直线构造，三个模型接口保留原来源连接 datum 的位置、向外轴、身份和 OD；Geometry 同次量测端面中心、法向与环面半径，越界即拒绝。它改变的是局部实体表示，不改变源轴、通用 frame 容差或 Data 的几何正规化。消费者必须读取 `shape.mode`；此模式的 frame PASS 只证明逻辑连接 datum 通过，不能声称端面法向与源轴完全相同。

曲主管/曲颈的另一个已实现分支在明确的转角、弓高和支轴偏差预算内选直纹放样或轴向锥颈，其余保留圆弧/Bézier 构造；端部源位置、方向、OD 保持。Geometry 使用共轴半径上包络组织主管、套环、过渡与末端，分别联合外实体和通腔，最后一次扣孔，避免先切主管再融合支管而封堵孔道。它要求结果有效、恰好一个实体和一个闭壳，并量测三个实际环形端面。布尔成功及 frame PASS 仍不足以独自证明全通道；需按目标读取保存 BREP，检查端面、孔道和材料。

**建议。** 遇到曲面/布尔失败，先定位首个失效操作及其输入形体，再区分截面定义、曲线条件、相交关系、融合次序、扣孔和端面识别。只有找到跨输入成立的几何准入或构造规则，才改共享资源；必要时用保存 BREP 与原失败输入核实体、环面和孔道。单件调整弯曲半径、套环厚度或 OCCT 容差，若没有参数域与反例证据，不能写入通用 prompt 或资源默认值。估计误差是选择表达的门槛，成功端面误差仍须由实际 shape 量测；未量测整表面时不声称全局几何误差上界。

## REG：有限空间求解、尺度与组合

**已实现。** REG 将高低压两侧视为独立的有限来源段；压力侧身份不由 OD 或图形左右推断。详细解用固定主体和两件共享两口 Geometry 适配件，分别匹配外部 OD 与主体内口。主体是可统一缩放的 mapped model，缩放同时作用于主体形体和主体接口；适配件是 `modeling_function`，靠真实尺寸参数构造，不再叠加系统业务尺度。数值搜索按当前资源声明的 `[0.4,1]` 范围有界寻找站位、朝向、适配件和必要缩放；外管轴、窗口及外口 OD 不随主体缩放。compact 保留真实主体但以名义球形适配件连接；node 则用完整名义端口的球形片段表达。数值解只选择尺度与片段参数，后端负责实际接口检查。

**建议。** 有限空间中先从两侧来源段及已确认相邻端口建立可用站位窗口和身份约束，再试详细布局与合法尺度；布局不可得时按该 Family 的已授权级别转 compact/node，并保留原因。不要为了匹配外管 OD 私下缩放主体，或以比例变化移动来源端点。不同构件组合可共享 exact Geometry，但每个片段的绑定、尺度、位姿和接口必须有唯一来源。找到候选尺度只证明存在一个可验证见证，不证明未采样的全部尺度不可行。

设备本件有限求解、实际返回端口与后续安装修改应分开记录。当前 REG 能在给定有限范围内求高低侧端口；需要安装时，再以这些端口与原管身份规划剩余管段、替换/修改外管及 IFC 结构，由后续职责执行。父 PIPE 尚未分段不能反向抹掉已完成的 REG 求解，也不能把本件成功升级为安装成功。

## 名义接口与实际连接

**复用的检查边界。** 同次 Geometry 接口是带位置、向外轴、参考方向和 profile 的模型 frame；Family finalizer 比较内部配对及显式外部条件。本轮将公开输入替换为三种标准条件，复用原位置、方向、OD 及可选 roll 残差检查；不自动回读并授权外部实体，实际外部连接状态仍为 NOT_CHECKED。阳极与宿主 datum 等非管附着不强制圆形管道外径检查，不增加外管内径匹配。TEE near_zero 的来源连接 datum 与物理端面有受限差异；REG compact/node 的球体端口是名义接口。有限站位、名义占用 clear 也不等于 BREP 无碰撞。

**建议给后续连接检验。** 先以准确来源管段、完整成员、各自许可窗口和保存的世界端口判断轴向站位及名义占用；共享产品涉及多个来源段时联合考虑约束。单段窗口收紧提示不是联合可行解，重叠需由正常 Family 求解验证候选布局。严格端点不匹配先分开检查投影算术舍入、保存坐标的机器精度微越界与实际空间越界；是否改变端点规则属于明确的设计决策，不能在单件检查里暗中放宽。进一步的实体端面贴合、外管交切、碰撞、贯通、真实端口/关系及 IFC 保存回读各需所属阶段的独立证据；不要由名义关系自动推断。

## 最小失败诊断与材料沉淀

建议按首个失败边界收集最少充分证据：exact 输入和版本、当前选择的表达/绑定、Family 状态与原因、失败的数值区间或关系成员、Geometry 的首个异常步骤与相应形体、必要时的保存 BREP/端面回读。先排来源身份和单位，再排数值域与准入，最后排构造、Codec/保存和跨产品关系；失败若发生在后层，不要回写前层状态。高成本样本先用已有只读结果缩小范围，确需真实构造才运行受影响代表；保留旧失败与新结果的准确身份。

正式 prompt/skill 可把上述顺序写成短决策模板，并链接本页与 exact 资源 usage，而不嵌入实例答案或固定调参表。通用规则需要来自不同几何尺度、转角和关联关系的反例验证；单个 CAD 例子只能给出假设与局部证据。工具改进与 Agent 指导同时变化时，分别记录改动和效果，不能单独归因；SYSTEM 发布、独立 Agent 理解/创作和 IFC 安装效果仍以各自后续验证为准。
