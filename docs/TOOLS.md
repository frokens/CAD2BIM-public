# 工具与结果的含义

| 工具 | 职责 | 结果边界 |
| --- | --- | --- |
| Data 查询／派生 | 读取准确输入、计算并发布新的不可变输出 | 不自动裁决管道与设备的安装关系 |
| `ifc_product_realization_preview` | 根据准确族、参数和显式连接条件求解／构造候选 | 候选不是保存后的模型，不证明外部管道已经协调 |
| `ifc_products_apply` | 添加该批产品并保存明确的提交结果 | 不自动裁切、移动或重建相邻产品，不自动创建网络连接 |
| `ifc_products_edit` | 对准确已有目标执行 replace／placement／delete | Agent 决定关联、动作和输入，后端执行该次明确请求 |
| `ifc_products_read` | 读取所选对象或原 Apply 报告 | 原报告是历史快照，不随后续编辑自动更新 |
| `ifc_query_python` | 执行 Agent 明确编写的 IFC 调查程序 | 由程序选择对象与比较方法，不隐含通用几何匹配 |
| `operation_get` | 导航状态、准确输入、输出 Package、表与代码 | 大业务表通过 Data 分页读取，不塞入操作摘要 |

`interface_constraints_evaluated_product_count` 等检查统计只描述该产品针对显式输入条件的求值。
例如设备接口落在给定有限段内，不表示已有管道实体的端点就在该位置。仍需比较实际保存的管端、
方向与截面，并显式维护不一致的对象。

完整逐行报告和 `interfaces.component_global_id` 可用于追踪该次真实保存的组件身份。
replace 后应使用最新成功操作及当前对象，不能把已被替换组件的接口观察当成当前模型。
Family 命名接口不是 `IfcDistributionPort`，接口数值一致也不是实体净空、密封或通流证明。

安装维护 Skill 使用通用调查和判断：结合原关系、完整路径、共享设备两侧及设备内部占用，
在原允许条件内协调；无法完成时保留当前有效状态、来源与未决原因，主动向用户报告业务缺口。
