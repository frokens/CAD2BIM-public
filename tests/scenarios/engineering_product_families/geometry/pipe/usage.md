# PIPE body Geometry

This `modeling_function` receives **Family-local** coordinates. `interfaces.py:evaluate(ctx)` declares `inlet` and `outlet` from the path endpoints and tangents without loading native geometry. `main.py:build(ctx)` creates one OCCT solid from the entire ordered polyline; both entries share `parameters.py:prepare(ctx)`. The full source point list remains the parameter and receipt fact. For construction only, consecutive exactly forward-collinear segments may become one equivalent segment; this neither drops input points nor changes the represented centerline.

| Input | Meaning and supported domain |
| --- | --- |
| `local_points_m` | Complete ordered 3D centerline in metres, relative to the fragment-local anchor and axes. At least two points; 128 is the current Schema/Runtime array capacity, not a business path limit. Adjacent segments must have positive length. |
| `endpoint_reference_directions` | Two unit vectors perpendicular to inlet/outlet axes, expressed in this same local frame; the Family inverse-transforms the original interface references so placement preserves their world roll. |
| `outer_diameter_m` | Known outside diameter in metres, finite and strictly positive. It is not DN or an inferred inside diameter. |
| `section.known_wall_thickness_m` | Empty list `[]` means wall thickness is unknown and only the OD envelope is modeled. A one-value list `[t]` means a sourced wall thickness and a hollow tube, with `0<t<OD/2`. No zero wall thickness is invented. |

The Geometry program derives retained source indices in order. An interior point is omitted from that temporary construction chain only if exact integer/power-of-two arithmetic on the represented input coordinates proves both incident edges collinear and forward. It adds no angle or distance tolerance; a small nonzero turn, foldback, or numerically unproved alignment is retained for the applicable domain checks and construction. Each retained segment starts from a circle represented by two exact semicircular arcs; a sourced inner circle uses the same representation. Extrusion keeps these side-face boundaries (`clean=False`) instead of merging them into one periodic cylindrical face. The circular or annular material is unchanged. The extended cylinder is then intersected with two clipping volumes bounded by its end planes. At an interior joint, the common miter-plane normal is the normalized sum of the neighboring forward unit tangents; the two terminal planes are normal to the terminal tangents. The clipped segments are fused sequentially. The final result must be valid and contain one solid and one shell; no per-fusion diagnostic scan is added. This is a mitered-segment construction, not a whole-path `right` sweep, and does not guarantee all numerically difficult inputs will construct successfully. A solid envelope is a volume for spatial modeling, not evidence that a real pipe has a filled bore. A known wall thickness creates an annular body whose measured end area is `π[(OD/2)^2−(OD/2−t)^2]`.

`inlet` is at the first local point with axis opposite the first segment tangent. `outlet` is at the last point with axis along the last tangent. Each declares the actual outer circular profile. The Geometry consumes `endpoint_reference_directions` in this same local frame. The Family retains its original world-Z/X reference convention when solving and inverse-transforms those references along with the body; Geometry does not recompute that convention after rotation. The Family and independent BREP inspection must verify the terminal planar face, outward normal, end area, total circular boundary and radii, and one or two end wires; one physical circle may consist of multiple arc edges. Merely comparing interface metadata is insufficient.

The authoring Schema enforces closed parameter keys, finite JSON numbers and array capacity. The Family numeric Program rejects domain defects and miter space defects before Geometry. OCCT may still reject very small or geometrically difficult but mathematically positive features during intersection or fusion; such a failure is a technical/build diagnostic, not a new fixed metre minimum. No coordinate, OD, total length, 1 mm, 16-point, or 19-point geometric bound is set here. Runtime document and IPC byte budgets remain separate limits.

Inspect the selected exact Geometry info, Schema and source before use. The evaluated interfaces describe named numerical connection datums; the exact saved BREP supplies entity evidence. A local usage file or self-check does not replace the selected immutable version or update its stored instructions.
